## 4. R3 修复后的关键决策

1. **布局开关归插件所有，不归 CM6 的 class**：`view.dom.style.paddingRight` + rail inline `display`；CM6 `updateAttrs()` 不会清除 inline style。
2. **只有一套纵轴**：Canvas 行、块带、滑块、caret 都调用 `docYToRail`；锚点只估算每行 `docY`，不改变比例。
3. **终端样本必须存在**：`(doc.lines, docHeight)` 只用于插值，保证文末块与轨道底一致。
4. **媒体块必须锚定**：图片/媒体行生成 block 边界，避免 Live Preview widget 造成 `docY` 重复。
5. **可见性用 inline display**：不依赖 `hidden` + author CSS 的优先级。
6. **性能门禁分两层**：C-008 纯函数 bench；C-011 真实 Chromium 100k rebuild（`qm-minimap-build` 事件采样）。
7. **点击验收独立计算期望值**：E2E-014 用 `headingDocY + pt - clientHeight/2`，防止 28px 回归。
8. **CSS 选择器必须用 `&`**：`EditorView.theme` 的 key 不能用最终 `.cm-editor` 字面量。
