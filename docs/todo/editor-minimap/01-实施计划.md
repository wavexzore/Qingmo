## 1. 实施结论

青墨已经有 CM6 单一文档状态、Live Preview、滚动持久化和主题 token，但右侧没有任何全文导航。用户要的是 VS Code 式编辑器 minimap，不是图片缩略图。采用的实现是：在 `EditorSession.extraExtensions` 追加一个 Canvas `ViewPlugin`；Source 模式把真实源文本按 1:1 比例缩小绘制（字符约 1px、行高约 3px），Live Preview 模式去掉 Markdown 标记并按真实块高绘制标题带/代码卡/表格/引用/媒体等渲染块；Canvas 与滑块共用同一个 `docYToRail` 纵轴，锚点只用于估算每行 `docY`（避免对 10 万行逐一 `lineBlockAt`）；rail 绝对定位在 `view.dom` 右侧，并通过 `.cm-editor` 的 inline `padding-right` 为正文让位（不用 class，避免 CM6 `updateAttrs()` 重写）。

这是最小风险方案，因为：

- 文档仍只来自 `EditorState`，滚动仍只来自 `scrollDOM`，主题仍只来自 `--qm-*`，持久化仍只由 `ViewStateRecorder` 写入；
- 不修改 `createEditorState`、`EditorHost`、`basicExtensions`、`qingmoEditorTheme`、`ViewStateRecorder`；
- 不新增配置、DB、Rust、IPC、共享类型、第三方依赖；
- 回滚只需移除 `EditorSession.ts` 中的一行扩展注入。

明确不做：DOM 克隆、真实字体轮廓还原、语法高亮、搜索/诊断标记、左右切换、宽度设置、持久化开关、嵌套代码块 minimap。

实施已完成：T-001~T-007、T-009 全部 `done`，T-008 按 Q-002=B 保持 `skipped`。Q-001~Q-007 已于 2026-10-30 由用户全部采纳推荐，最终组合为 `B/B/A/A/A/A/A`，已写入本计划与 `README.md §12`；若未来变更须先更新计划、README 与 `02-实施状态与验证.md §9`。

## 4. 目标方案

### 4.1 目标链路

```text
EditorSession 构造函数
  -> extraExtensions = [ ...原有项, minimapExtension() ]
  -> createEditorState
  -> EditorHost new EditorView
  -> Minimap ViewPlugin
     -> eligible? (>=80 lines, <=100k, <=2M units, width>=640)
     -> scan doc -> lines/blocks
     -> lineBlockAt anchors -> AnchorMap
     -> buckets -> Canvas
  -> scroll/pointer/theme/resize
     -> slider / redraw / scrollDOM.scrollTop
  -> ViewStateRecorder 不变
```

### 4.2 设计决策
