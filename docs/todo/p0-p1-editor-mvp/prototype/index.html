# 在湖边

一篇关于清晨、湖面和注意力的随笔

清晨六点，湖面像一张还没有写字的纸。风从芦苇丛里穿过去，水面只动了一下，又很快恢复平静。

我带着一台旧电脑坐在岸边，没有网络，也没有通知。屏幕亮起来的时候，我忽然意识到，自己能听见的只剩下键盘的声音。

## 一 · 清晨

写作不是把想法倒出来，而是把它放到一个可以反复看见的地方。那些在脑子里显得完整的句子，落在纸上以后，往往还需要再走一段路。

> 好的工具应该退到文字后面，而不是站在文字前面。

所以我把编辑器做得尽量安静：没有多余的按钮，没有跳动的提醒，也没有一个不断催促你保存的进度条。

  • - 把文件留在本地；
  • - 把注意力留给句子；
  • - 把复杂留给以后。

我把这种状态叫作 `local-first`：文件先属于你，软件只是入口。

## 二 · 纸与笔

太阳升起来以后，湖面开始发亮。我合上电脑，把没有写完的句子留在屏幕里，也留在自己的机器上。

这大概就是“青墨”想做的事：不替你写作，只替你把纸和笔准备好。

如果你也喜欢这种节奏，可以读一读 《Local-first software》。
