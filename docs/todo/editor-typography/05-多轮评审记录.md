### 3.2 R2 确认正确、不要改的部分

1. theme facet 是 prefix 字符串；不同 `(fontSize,fontFamily)` 会产生不同 style module/prefix，从而触发 `mustMeasureContent` 与 `requestMeasure`（`view 6853, 8094-8097, 8829-8831`）。
2. `replacePayload` 传 `this.typography` 足够，不需要 `typographyApplied`；`view.setState` 会重建 plugins 并设置 `mustMeasureContent = true`（`view 6291`）。
3. 当前路由下 `WorkspaceLayout` 的 layout effect 先于 `EditorHost` 的 passive effect；StrictMode、document window 异步加载、route transition 都成立。
4. `transaction.reconfigured` 覆盖 compartment 重配；正常路径 minimap 会重建 geometry/anchor/scale/rail/slider。
5. computed-style E2E 可行；`font-family` 返回完整 token 栈，`line-height` 需要 px 比值。
6. `--qm-content-max: 72ch` 确实未消费；默认 15/mono/1.75 与当前行为一致；不新增 Rust/IPC/DB 的边界正确。
