## 1. 实施结论

1. 当前编辑器排版只有一套硬编码值：`15px` / `mono` / `1.75`，写在 `editorThemeSpec`；Settings 只有语言，没有字体入口。
2. 推荐路径是“共享纯模型 + 独立 typography compartment + 现有 uiStore/storage 同步 + Settings 第二个 section”。默认值等于当前行为，升级无视觉变化。
3. 这是最小风险方案：不动 Rust/IPC/DB/原生菜单；不重建 `EditorView`；不修改 `EditorHost`/minimap；只新增一个 localStorage 配置项（Q-001 已批准）。
4. 明确不做：行高、阅读宽度、应用级 zoom、代码块独立字号、系统字体枚举、每文档排版。
5. Q-001 ~ Q-005 已于 2026-11-04 全部采纳推荐项 A；LLM 可从 `T-000` 的校准结果开始，按 T-001 → T-009 顺序执行。

### 2.4 官方文档与 GitHub 开源实现调研

> 详细证据见 `research/01`、`research/02`、`research/03`。这里只固化采用/拒绝理由。

| 来源 | 关键事实 | 采用/拒绝 |
|---|---|---|
| CodeMirror Styling | 不要求等宽字体或固定行高；theme 是扩展 | 采用 `EditorView.theme` |
| CodeMirror Ref | theme facet 变化自动 `mustMeasureContent`；`setState` 重建插件 | 采用 compartment；拒绝 rebuild |
| CM6 6.43.15 源码 | ResizeObserver 只观察 scrollDOM | 拒绝纯 CSS 变量 |
| WCAG 1.4.4/1.4.8/1.4.12 | 200% 放大；≤80 字符；≥1.5 行高 | 保留 1.75 行距；不宣称整体合规；行长独立 |
| Typora | 9–24，根 html font-size；字体族仅 CSS；zoom 独立 | 拒绝根 html；采用“字号+独立 zoom”边界 |
| MarkText | 12–32，字体族自由文本，行高 1.2–2.0 | 采用 range/step；拒绝自由文本/行高 |
| SiYuan | 字号/字体设置 → CSS 变量；行高固定 | 采用“少量设置+固定行高” |
| Logseq | CSS 变量 + data-font，无直接 UI | 拒绝“只能写 CSS” |
| Joplin | `style.editor.fontSize/fontFamily` + CM6 createTheme | 采用全局设置 + CM6 主题 |
| Rello 2016 | ≥18pt 更好；18/26 理解更好；0.8/1.8 极端有害 | 范围含 24px；默认保持 15 |
| Dyson 2004 | 字符/行是关键；长行更快但偏好 55 | 不改行长；列为未来 |
| Zhu 2021 | 中文字号/行距影响阅读时间/疲劳 | 保留 1.75；字号可调 |
| Beymer 2008 | serif/sans 无显著差异 | 三预设作为偏好 |

## 3. 设计决策

| ID | 决策 | 理由 | 替代方案 |
|---|---|---|---|
| D-001 | 范围 = 字号 + 字体族三预设 | 最小可用；证据支持 | 仅字号 / 加行高 / 加行宽 |
| D-002 | 字号 12–30，默认 15，步进 1 | 覆盖 24px 推荐点；默认不变 | MarkText 12–32 / Typora 9–24 |
| D-003 | 字体族 mono/sans/serif，默认 mono | 现有 token；默认不变 | 自由字体栈 / 系统枚举 |
| D-004 | 全局偏好，单个 JSON localStorage 键 | 原子、可迁移；与 theme/language 同层 | 两 scalar 键 / session-only / Rust |
| D-005 | 纯模型放 `packages/shared` | editor-core 与 app 都依赖；无 DOM | 放 editor-core / app |
| D-006 | 新 `typographyCompartment`，不扩展 theme | 职责单一；避开 HIGH | 扩展 themeExtension |
| D-007 | `editorThemeSpec` 删除 base 字号/字体/行高 | 单一来源 | 保留并让 typography 覆盖 |
| D-008 | `EditorSession` 持有 typography；构造可选 seed、replacePayload 传 factory | reload 正确；生产首帧由 layout effect seed | 只在 hook 中 apply |
| D-009 | `useLayoutEffect` 投影 | 在 EditorHost passive 前 seed | `useEffect` |
| D-010 | `UiSnapshot.typography` + `setTypography` + sync filter | 复用现有模式 | 新 store / Rust |
| D-011 | Settings 第二个 section | 不新增路由/Tab | 新 nav / 独立窗口 |
| D-012 | 原生 range + radio + preview + reset | 可访问、无新组件库 | 复用 LanguageSelect |
| D-013 | 保留外层六块，只收敛 `1.75` 常量 | 消除行高双源；避免 R2 级联回归 | 删除外层六块 |
| D-014 | `EDITOR_LINE_HEIGHT=1.75` 常量 | 行高固定但值单一 | 三处字面量 |
| D-015 | 不加命令/菜单/快捷键 | 首版最小 | 加 command palette |
