## 6. R7 范围变更：BYOK 远程转写

用户提出可参考 `/Applications/superwhisper.app` 的「本地 + 远程」双方式。实测证据（3.2.1，`Info.plist` + 二进制字符串 + 支持目录）：

| 事实 | 证据 |
|---|---|
| 远程 provider 为 OpenAI / Groq / Deepgram / ElevenLabs | `api.openai.com/v1/audio/`、`api.groq.com/openai/v1/audio/`、`api.deepgram.com/v1/listen`（含 `wss://`）、`ElevenLabs Scribe V2` |
| BYOK + keychain | `Bring your own API key`、`Your own API keys`；keychain 串来自许可证激活告警（间接证据，BYOK 存储实现未反编译） |
| 组织级关闭云模型并自动降级 | `Cloud models are off, moving the meeting mode off cloud models` |
| 本地多引擎（含自有模型市场） | `ggml-large/small.bin`、`s1-mini-v080-iq4_xs.gguf`、`cohere-transcribe-q4`（MLX safetensors）、`parakeetkit-pro`、`superdiarize`、`supervocab` |
| 模型清单带哈希与版本 | `model-manifest.json`：`sha256`、`revision`、`eTag`、`models.superwhisper.com` |

采纳：双后端、本地默认、远程需显式开关、失败只回退一次、BYOK。
不采纳：自有云模型（S1-Voice）与账号体系；ElevenLabs（本项目不涉及实时听写）；MLX/Cohere 运行时（Rust 侧无法直接复用）。

对应修改：R-002 改口径、新增 R-011、新增 D-011/D-012、新增 `RemoteAsr`/`asr_route`、配置 8→13 项、新增 T-004b、AC-011/AC-012、原型加「转写方式/提供方/转写密钥」。
