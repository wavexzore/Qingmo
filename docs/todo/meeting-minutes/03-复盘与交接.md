### 6.2 配置说明

| 配置 | 推荐值 | 注意 |
|---|---|---|
| `asr.mode` | `local` | 远程才上传音频；失败只回退一次 |
| `asr.localModel` | `null`（自动） | 自动按内存分层；显式值只认 `Asr` manifest id |
| `llm.mode` | `local` | 远程需填 URL 与密钥；本地慢但不出网 |
| `llm.localModel` | `null`（自动） | 自动按内存分层；显式值只认 `Llm` manifest id |
| `runtime.mode` | `auto` | `cpu` 关闭 Metal，用于排障 |
| `maxMinutes` | `180`（5..=600） | 超限在选文件时拒绝 |
| `keepTranscript` | `true` | 关闭会失去回听依据 |

## 7. 已知限制

| 限制 | 影响 | 后续建议 |
|---|---|---|
| ASR 第一版纯 CPU | 1 h 音频约 5–15 min | NEXT-009 评估 CoreML/whisper Metal |
| 首次使用需下载模型 | 无网首次不可直接用；转写组合 265 MB，摘要模型 1.1–5.0 GB | 设置页引导 + 续传；必要时随包 small |
| 本地摘要质量/速度有限 | 1.7B/4B 弱于远程；低配慢 | 切远程或接受抽取式；NEXT-016 |
| 说话人只有编号 | 不能把「说话人 1」自动变成姓名 | NEXT-002 |
| 分离有聚类误差 | 同名同姓/音色接近可能合并或漂移 | 重要结论以引句为准 |
| 分离峰值内存高于预算 | 分离实测约 231 MB，`DIARIZATION_MB` 仍按 160 MB 预留 | 低内存档需留余量；后续上调预算并复测 |
| 关窗即取消 | 不能后台续跑 | NEXT-006 |
| 无任务历史 | 关掉后不可重开 | NEXT-008 |
| 中文评测集需自建 | 阈值仅覆盖 40 条自建样本 | 已用 40 条完成校准；行业基准仍缺 |
| Windows 安装包无 Authenticode | SmartScreen 可能拦截 | 真机安装需手动放行；后续在 Windows 签名 |
| Linux 未打包 | 无法交付 Linux | 批次 6 跟进；当前 compile-only |
| 官方源 E2E 不在 CI | 上游漂移只靠手工 `E2E_OFFICIAL=1` 发现 | 定期手跑并核对 pin；后续进夜间任务 |
| 下载无 idle 读超时 | 停滞时需手动取消重试（总超时 2 h） | 后续加读超时与指数退避 |
| 关闭握手超时后偶发 BUSY | 「保存失败 → 仍要关闭」后下一任务短暂 `MEETING_BUSY` | 重启恢复；后续在超时分支补 release |
| 长会议聚类阈值样本有限 | 真实 21 分钟双人通话已稳定为 2 人；更长/多人会议仍可能多标 | 后续用真实语料扩充校准集 |
| 远程摘要依赖网关 JSON 契约 | 已兼容数组/单对象/包装与字符串 `speaker`；网关若返回纯文本仍整窗降级 | 提示词约束 + `last_error` 可见降级；后续按厂商补适配 |
| 密钥明文随 config.json | 备份/同步该目录会带出 API Key；文件权限 0600，仅本机用户可读 | 不把配置提交版本库；后续可评估加密存储 |
