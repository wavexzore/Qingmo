## 1. 实施结论

应用只有一条「读取 UTF-8 文本」的打开链路，音频进不来，也没有可取消的长任务框架。本计划新增一条完全并行的会议链路，产物仍是普通 untitled 文档：Rust 侧完成解码、离线说话人分离、VAD、本地识别、结构化摘要与校验；WebView 只收进度与最终 Markdown；保存继续走 `SaveCoordinator`。安装包不携带任何模型，首次使用由设置页引导下载转写组合（约 254 MB），摘要模型可选，之后按任务选择加载。

这是最小风险路径：`document_open`、`ensure_supported_extension`、`take_pending`、`AtomicWriter` 全部不动，只在窗口 URL 参数、命令注册、菜单、错误码四处开口。被否决的方案见 `04-设计方案.md §14`。

明确不做：麦克风、说话人姓名识别、自建云 ASR 服务、跨重启续跑。

T-001/T-002 已完成；R26 将设置改为「转写模型/摘要模型 × 本地/远程」，新增本地 LLM 与运行时分层；`Q-010/Q-011` 已于 2026-11-10 裁决为 A/A；R28~R41 均判 REJECT；逐窗单遍、概率补丁、预算、路由矩阵、E2E 接线、出口表与取消路径已修，R42 终审 PASS，T-003 解冻。

### 4.1 目标链路

```text
menu / palette
  -> meeting_start
  -> dialog + 校验 + MeetingRegistry.begin
  -> untitled 窗口(?meeting=id)
  -> decode -> vad -> asr -> gate -> cards -> reduce -> validate -> render
  -> meeting_take_result -> startUntitled() + insertDocumentText(markdown)
  -> SaveCoordinator（不变）
```

### 4.2 设计决策

| D-ID | 决策 | 理由 | 拒绝方案 | 影响任务 |
|---|---|---|---|---|
| D-001 | 全 Rust 流水线 | CSP、密钥、取消 | 前端直连 | T-001~T-007 |
| D-002 | 复用 untitled 窗口 + query | 零新窗口体系 | `meeting.html` | T-008 |
| D-003 | sherpa-onnx + Paraformer int8 | 中文 CER 1.31、Apache-2.0、静态 | whisper.cpp（中文弱、公证贵） | T-002、T-003 |
| D-004 | 两级 map-reduce | 长上下文衰减 | 单级/refine | T-004 |
| D-005 | 引句 + 回查 | 事实一致性 | 纯 LLM 自评 | T-004、T-005 |
| D-006 | 无 LLM 抽取式 | 断网可用 | 直接失败 | T-004 |
| D-007 | 菜单 + 面板双入口 | 与现有命令一致 | 工具栏按钮 | T-009 |
| D-008 | 不新增表 | 产物是文件 | 任务历史表 | T-006 |

| D-019 | 概率缺失如实 `None` | 默认模型无概率，避免恒假门 | 伪造 NaN/恒 1.0 | T-003、T-005 |
