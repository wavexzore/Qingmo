> **功能 ID：** `i18n`
> **文档版本：** v1.0（2026-10-28）
> **代码基线：** `main@195bfb6` + 工作树 WIP

## 1. 实施结论

1. 当前仓库已有 **中英资源层** 和组件级 `useTranslation`，缺的是“运行时切换 + 持久化 + 原生外壳投影 + 编辑器内核注入”。
2. 推荐方案不是再引入一套 i18n，而是把语言并入现有 `UiStore`，新增一个 `LocaleController` 做跨层协调；前端仍是唯一文案源，Rust 只渲染前端投影的 `NativeShellLabels`。
3. 原生菜单/窗口标题需要新增 **1 个 IPC 命令**（`app_apply_locale`）、**1 个权限**（`allow-app-apply-locale`）、**1 个错误码**（`INVALID_LOCALE`）、**2 个菜单 action**；不新增依赖、不新增数据表、不新增 `settings.json`/`tauri-plugin-store`/`i18nextLng`。
4. 编辑器 Widget 通过 CM6 `EditorUiCopy` Facet 注入，不把 i18next 带进 `packages/editor-core`；`EditorSession` 只做加法，不改保存/关闭/冲突/IME 路径。
5. 当前工作树精确计数：`editor-core` 非测试 `.ts` 含中文 **92 行**（2 行注释、5 行解析默认值、6 行错误卡文案、79 行直接 DOM/可访问文案；即 **90 行最终可见/可访问**）；命令 **19**、事件 **4**、错误码 **19**、前端基线 **391** 测试。实现后必须由测试断言这些计数，而不是文档硬编码。

> 选型规则：优先复用现有层；不引入第二套状态/文案/存储；新增文件必须有单一职责和测试。

## 4. 目标方案

### 4.1 目标链路

```text
UiStore（唯一持久化：theme + language）
  -> i18n.init(lng=language)
  -> LocaleController（唯一协调器）
       -> i18n.changeLanguage
       -> <html lang>
       -> buildNativeShellLabels(language)
       -> app_apply_locale -> Rust ShellLocale -> set_menu / titles
  -> React useTranslation
  -> EditorPage -> placeholder Compartment / EditorUiCopy Facet
  -> lib/format -> Intl
```

### 4.2 设计决策

| D-ID | 决策 | 理由 | 备选/拒绝 |
|---|---|---|---|
| D-001 | 语言并入现有 `UiStore`，键 `qingmo.ui.language` | 复用主题的持久化/同步/降级 | 新 store/插件（第二状态） |
| D-002 | 默认 `zh-CN` | 不改变现有行为 | 跟随系统/默认英文（Q-003） |
| D-003 | 前端是唯一文案源；Rust 只接收 `NativeShellLabels` | 防止第二份翻译漂移 | Rust 中英表（拒绝） |
| D-004 | Rust `ShellLocale` 只存进程内状态，不落盘 | 避免第二持久化层 | 文件/插件 store（拒绝） |
| D-005 | `app_apply_locale` 同步命令、幂等、`set_menu` 后提交状态 | 避免并发/重复重建；失败可重试 | async + 锁外构建（复杂） |
| D-006 | 原生菜单用 `AppHandle::set_menu` 运行时替换 | 官方支持，保留窗口/编辑状态 | 重启/重建窗口（拒绝） |
| D-007 | 启动用中性标题 + 安全中性菜单（自定义 `MENU_QUIT`），首帧后投影 | Rust 读不到 localStorage；避免中文首帧；不能把 CloseGuard 交给平台默认 Quit | Rust 启动文案表（拒绝） |
| D-008 | `EditorUiCopy` CM6 Facet，不引入 i18next | 保持 editor-core 纯包、按 view 可重绘 | import i18n/全局单例（拒绝） |
| D-009 | placeholder 用 Compartment 重配置 | 不重建 state，保留 undo/selection/IME | `replacePayload`/重建（拒绝） |
| D-010 | `lib/format` 统一 `Intl` 日期/时间/字节 | 一处实现，语言一致 | 各处 `toLocale*`（拒绝） |
| D-011 | 不新增依赖/数据表/`i18nextLng` | 控制范围与迁移 | detector/plugin-store（拒绝） |
| D-012 | 原生“显示 > 语言”子菜单 + 命令面板两个命令 | 鼠标/键盘都可发现 | 仅命令面板/About（拒绝） |
| D-013 | About 复用 `LocaleController`（`native:null`） | 同一协调逻辑，不写第二份 | 单独 changeLanguage（拒绝） |
| D-014 | 测试动态遍历 namespace、复数类别、插值、汉字扫描 | 防资源/文案漂移 | 硬编码列表（拒绝） |
| D-015 | 新 DTO 从 Rust `ts-rs` 生成，前端不手写 | 单一契约源 | 手写镜像（拒绝） |
| D-016 | 删除 `APP_NAME`/`APP_TAGLINE` | 消除第二文案源 | 保留（拒绝） |
| D-017 | 新增 `INVALID_LOCALE`，校验 label 非空/长度/控制字符/`.md` | 防止空菜单/路径注入 | 不校验（拒绝） |
| D-018 | i18n `languageChanged` 同步 `<html lang>` | 无障碍/拼写检查/字体 | 只改 React（不足） |

### 4.3 兼容性策略

- 旧版本没有 `qingmo.ui.language` -> 读取失败返回 `zh-CN`，行为不变。
- 旧前端不调用 `app_apply_locale` -> Rust 使用中性标题/安全中性菜单，仍可运行。
- 新增命令/权限/错误码是追加；`commands_contract`/`security_config` 同步计数。
- 不改变文件格式、保存协议、更新协议；启动安全中性菜单的 Quit 必须走自定义 `MENU_QUIT -> request_close`，不能依赖平台默认 Quit 或 `ExitRequested`。
- `EditorSession` 新方法可选，旧测试/旧调用不需要改造。
