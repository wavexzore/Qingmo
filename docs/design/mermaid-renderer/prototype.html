01 / 默认态：图表作为“图版”嵌入正文，不抢走段落的注意力。 悬停图表可查看缩放与源码操作；点击图表本体回到源码。

02

交互状态

所有状态都保留图版骨架：不跳动、不空白、不把错误堆成另一套界面。

悬停与工具

A / HOVER

工具条浮在标题栏内，不改变画布高度；离开后回到“点击「源码」编辑”的提示。

正在绘制

B / LOADING

用抽象节点而不是通用 spinner 表示“正在排版”，并保留画布高度，主题切换时不跳版。

渲染失败

C / ERROR

错误只占一行，保留“编辑源码”这一条出路；不带红色大色块，也不替换整段文档。

源码态

D / SOURCE
```mermaid flowchart TB A[想法] --> B[草稿] B --> C{可以发布?} C -- 是 --> D[完成] C -- 否 --> B ```

点击图表或“源码”回到 CodeMirror 原生源码，不新开编辑器；移开选择后自动恢复图版。

变量与尺寸

所有颜色从语义令牌取值，不在渲染器里另存一套十六进制。

MermaidQingmo token用途

  • 容器1px --qm-line，圆角 10px，标题栏 34px。
  • 画布内边距 22px 26px，图表最大宽度 100%，超宽时横向滚动。
  • 字号节点 14px、连线标签 12px、时序消息 13px；全部使用正文 sans。
  • 动效悬停 160ms ease-out；主题切换 160ms 交叉淡入；加载虚线 1.6s。
  • 降级失败保留“编辑源码”；超限直接显示源码；外部图表继续走代码块。
04

复杂样例

同一套图版骨架覆盖 C4 架构、子图、时序、类图、状态图、ER、Git、思维导图、象限图与甘特图；宽图占满，窄图按原始尺寸居中。

关于这组样例

宽图占满整行，窄图保持原始尺寸；所有类型共用标题栏、画布与主题令牌。

旅程、时间线等超宽类型仍待覆盖；失败与超限继续回退源码。
