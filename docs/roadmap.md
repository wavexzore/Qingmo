## 0. 摘要

Qingmo 已经具备真实的编辑内核：CM6 单一真源、Live Preview、原子写、冲突处理、关闭守卫、更新状态机。P2 核心也已闭环：本地图片、工作区根与虚拟文件树、SQLite/FTS5 全局搜索、版本历史、回收站、会话恢复与跨进程保存锁。当前缺口集中在**知识导航**（标签/反链/标签页/快速打开）、迁移与导出、完整设置、插件系统与跨平台验收。

推荐 9 个批次 + 1 个已交付增量、5 个可发布切片：

| 版本 | 批次 | 对外承诺 |
|---|---|---|
| `v0.2` | 0 | 可以放心拿它写第一篇长文 |
| `v0.3` | 1 + 2 | 有一个自己的笔记库，崩溃也不丢 |
| `v0.4` | 3 + 4 | 找得到、迁得进、导得出 |
| `v0.5` | 5 + 6 | 按我的习惯写，在三个平台都能装 |
| `v1.0` | 7 + 8 | 可扩展、可商业化的正式产品 |

**最先做的是修缺陷，不是加功能。** 多窗口化留下的四个高等级缺陷（`save_as` 泄漏旧 token、关闭确认无超时、`exiting` 不复位、先注销文档后 `destroy`）已在 P0/P1 收尾中清理；本批同时补上稳定 DocumentId、verified IO、16 MiB 统一边界、rename 配对、trash/10k 可达性与回滚工具。后续新功能必须以 `pnpm ci:local` / `ci:tauri` 与 ADR-0010 的边界为前置。

## 1. 排序原则

1. **先止损**：数据丢失、只读绕过、裂图、外链不可点，优先于任何新面板。
2. **先闭环再扩面**：单文件闭环稳定后，才允许扩到工作区与多文档。
3. **先底座再界面**：watcher、备份、快照、路径 jail 先于文件树与搜索 UI。
4. **先契约再实现**：IPC、设置、插件清单、存储格式先写 ADR，再写代码。
5. **先单平台真机再跨平台**：macOS 真实二进制验收通过后，才扩 Windows/Linux。
6. **每批可独立发布**：不合并成大爆炸版本；未达标条目回流。
7. **负例先行**：每批先写故障注入与越权用例，再写正常路径。

### 1.1 优先级判据

| 判据 | 权重 | 说明 |
|---|---:|---|
| 数据丢失/不可恢复 | 5 | 直接阻断长期使用 |
| 当前功能“假支持” | 4 | 看起来有、实际不可用 |
| 日常高频阻断 | 4 | 每次写作都会遇到 |
| 迁移/交付门槛 | 3 | 决定用户能否进来/出去 |
| 依赖前置数量 | 3 | 被依赖越多越早 |
| 生态/商业化 | 2 | 放大期能力 |

## 2. 非目标与暂缓

以下能力**不进入 v0.2–v0.5**：

- 实时协作、移动端、云端同步。
- 通用内置 AI 写作助手（会议纪要已作为垂直能力交付，通用对话/续写仍后置）。
- 71 语言全覆盖、Touch Bar、标题栏配件、匿名分析。
- 自定义主题市场、第三方插件市场（先有设置与主题目录）。
- 大规模 UI 重做（先补业务空洞）。
- 许可/付费墙（先验证留存）。

## 4. 批次详情

### 批次 0 · 可信编辑闭环硬化（P0，1–2 周）

**用户问题**：现在能编辑，但“多窗口 + 另存为 + 退出”不可靠，本地图片裂图，外链点不开。

**范围**

- 修 R-01：`document_save_as` 换 token 时释放旧 token，并补断言。
- 修 R-02：关闭确认加 3–5s 看门狗，超时窗口视为已确认并记日志。
- 修 R-03：`exiting` 在退出成功/取消路径复位。
- 修 R-04：`save_as` 后按新路径重新判定只读；混合 EOL 明示“将统一行尾”。
- 修 R-05：`destroy` 失败时回滚 token 与 registry。
- 只读绕过负例：MDX / 混合 EOL / 只读目录 / 符号链接换目标。
- 精确 10 MiB 边界：插入 1 字符后保存不得失败。
- 本地图片：文档目录基准、自定义协议或 `asset:`、scope、CSP 放行；粘贴/拖入落盘。
- 外链：`openExternal` 命令 + scheme 白名单 + capability。
- 真实 Tauri 二进制 E2E：至少覆盖打开→编辑→保存→冲突→关闭。

**依赖**：无。**可并行**：安全负例、E2E 脚手架。

**交付物**：修复 PR、ADR 修订（0002/0004）、故障注入脚本、真机 E2E 报告。

**退出标准**

- 多窗口 + 另存为 + 退出连续 50 次，无 token 泄漏、无挂起、无内容丢失。
- 本地相对图片在真实 Tauri 下 100% 可见；外链只放行 `http/https/mailto`。
- 精确 10 MiB 文件“插入 1 字符→保存”成功。
- `pnpm ci:local` + 真机 E2E 全绿。

**风险**：打开 asset protocol 会扩大攻击面 → 只给工作区/文档目录 scope，CSP 精确到协议，不开通配符。

### 批次 1 · 数据安全底座（P0，3–4 周）

**用户问题**：崩溃、误删、外部改动会丢字。

**范围**

- 版本备份：保存前保留最近 N 版，独立目录，按文档 ID 分桶，TTL + 容量上限。
- 崩溃快照：内容、光标、选区、滚动、未保存标记；启动扫描 + 恢复 UI。
- 外部变更 watcher：`notify` + 200ms 去抖 + 自写抑制窗；变更时提示重载/对比。
- 会话恢复：窗口、标签、光标、滚动；启动恢复失败回落空白。
- 回收站/重命名/删除 + 撤销（`TyFilesOp` 等价物）。
- 临时文件与陈旧快照启动清理。

**依赖**：批次 0 的 token 与关闭稳定。**可并行**：快照格式设计、恢复 UI。

**交付物**：备份/快照 ADR、恢复 UI、watcher 服务、故障注入用例。

**退出标准**

- `kill -9` 后重启，内容/光标/选区恢复，撤销栈可继续。
- 外部修改 200ms 内提示；自身保存不触发假冲突。
- 50 次恢复循环无内容漂移；备份容量达到上限后按策略淘汰。
- 误删可在 30 天内从回收站恢复。

**风险**：快照写放大 → 压缩 + 增量 + TTL；watcher 递归风暴 → 忽略 `.git`/`node_modules` + 深度/数量上限。

### 批次 2 · 工作区与导航（P0/P1，4–6 周）

**当前状态（2026-11-09）**：核心已交付——工作区根、路径 jail、虚拟文件树、大纲、单实例、Finder/文件关联、会话/打开意图恢复。剩余：重命名/右键菜单、最近文件/收藏、文档标签页、拖放、窗口几何恢复、`.qingmo/workspace.json`。

**用户问题**：只能开单文件，无法管理一个笔记库。

**范围**

- 打开文件夹 + 工作区根 + 路径 jail（canonicalize、符号链接、越界拒绝）。
- 文件树/文件列表：懒加载、虚拟滚动、搜索过滤、右键菜单（新建/重命名/删除/在 Finder 中显示）。
- 大纲面板：基于稳定块 ID，点击跳转，跟随光标。
- 最近文件、收藏、标签页、同文件去重。
- 单实例 + Finder 打开 + 拖放 + 文件关联。
- 窗口位置/尺寸恢复；新建窗口命令。
- 工作区级设置文件（`.qingmo/workspace.json`）。

**依赖**：批次 1 的 watcher/恢复/回收站。**可并行**：树虚拟化、导航交互设计。

**交付物**：工作区 ADR、路径 jail 负例、树/大纲/标签页、单实例与文件关联。

**退出标准**

- 1 万文件树首屏 <200ms，滚动不掉帧；10 万文件可用。
- 越界路径、符号链接逃逸、大小写冲突全部拒绝。
- 双击 `.md` 聚焦同一实例；同一文件不会开出两个编辑窗口。
- 关闭重开恢复窗口、标签、光标。

**风险**：工作区根引入越权面 → 所有路径先过 jail；大树卡顿 → 虚拟滚动 + 后台扫描 + 上限。

### 批次 5 · 设置与写作体验（P1/P2，3–4 周）

**用户问题**：不能按自己的习惯写，长文缺指标。

**范围**

- 设置存储 + 设置页（文件/编辑器/图片/Markdown/导出/外观/通用），设置迁移。
- 字体、行宽、行高、自动保存间隔、拼写检查、语言切换、主题目录/导入。
- 字数/字符/行数/阅读时间；格式菜单、工具栏、自动配对、缩进、移行、代码折叠。
- 智能引号/破折号、Emoji 补全、Ruby。
- 文档级 YAML 设置驱动渲染与导出。

**依赖**：批次 4 的设置契约。**可并行**：设置 UI、排版预设。

**退出标准**

- 设置项有 schema、默认值、迁移与重置；无硬编码文案。
- 语言切换即时生效，原生菜单同步。
- 写作快捷操作全部有快捷键与命令面板入口。

**风险**：设置公开即兼容契约 → 先 ADR + schema 版本；主题可写 → CSS 白名单 + 外链提示。

### 批次 6 · 分发与平台（P1，3–4 周）

**用户问题**：装不上、更新不可靠、只有 macOS。

**范围**

- Windows/Linux 构建与运行时验证；IME、菜单、路径差异。
- 全平台更新产物、签名、公证、beta 通道、失败回滚。
- 托盘（最近文件/新建/退出）、窗口恢复、文件关联、单实例回归。
- 崩溃日志、诊断包、更新真机验收。

**依赖**：批次 5 的功能面稳定。**可并行**：CI 矩阵、安装包脚本。

**退出标准**

- macOS/Windows 真机安装→重启→卸载全通过；Linux AppImage 启动可用。
- 更新失败保留旧版本；beta 可切回 stable。
- 三平台 IME/快捷键/菜单冒烟通过。

**风险**：平台差异大 → 先 Windows 编译+运行测试，再 Linux；签名证书 → 本地优先、CI 后置。

### 批次 M · 会议纪要（P1，已交付 2026-11-11）

**用户问题**：会后录音要手工分段、外部转写、复制粘贴，时间戳与结构全部丢失。

**范围**

- 选音频 → 解码/VAD/逐窗分离/本地 ASR → 结构化五节文档，复用 untitled 窗口与 `SaveCoordinator`。
- 设置页 13 项配置、模型清单/下载/续传/预检、keyring、硬件分层；本地默认，BYOK 远程失败回退一次。
- 零模型打包、公证、`NOTICE`、官方源与镜像 E2E、真实录音校准。

**依赖**：批次 2 的工作区/路径能力。**可并行**：无（流水线串行）。

**退出标准（已达成）**

- AC-001~AC-017 全 PASS；浏览器 12/12、原生 14/14、40 条校准达标。
- 安装包无模型；app/DMG 公证与装订；`otool` 无 libomp/vcomp；`NOTICE` 全许可随包。
- 官方源冷下载 234 MB 通过；缺包/磁盘不足/取消/降级均有稳定错误与恢复。

**风险**：模型体积与硬件差异 → 分层、预检与降级；许可漂移 → 固定 SHA 与 `NOTICE` 复核。

### 批次 7 · 插件生态（P1，6–10 周）

**用户问题**：不能扩展，无法形成差异化。

**范围**

- Plugin SDK、manifest schema、Ed25519 签名、`.qingmo-plugin` 安装包。
- Plugin Worker（逻辑）+ sandbox iframe（UI）+ Capability Broker（权限/路径 jail/网络 origin/速率/审计）。
- 安装/卸载/启用/禁用、崩溃隔离、3 次隔离、安全模式。
- 市场（列表/详情/版本/签名校验）、首批官方插件（导出、主题、AI）。
- 贡献点：命令、主题、渲染器、状态栏、设置页。

**依赖**：批次 2 的 jail、批次 5 的设置、稳定命令/事件契约。**可并行**：SDK 文档、示例插件。

**退出标准**

- 恶意插件矩阵（越界读写、任意网络、无限循环、崩溃、伪造签名）全部拦截。
- 插件崩溃不影响主窗；禁用即撤销权限与网络。
- 官方插件全部通过市场签名安装。

**风险**：API 反复破坏 → 先冻结 1.0 契约 + 版本化；性能 → Worker 配额 + 启动懒激活。
